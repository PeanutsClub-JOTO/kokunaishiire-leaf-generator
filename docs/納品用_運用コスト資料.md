# 企画業務自動化システム 運用コスト資料

作成日: 2026-07-23（更新: 2026-07-24）

## 1. 前提

この資料は、2026-07-23時点の公式料金ページと現在の実装をもとにした概算です。

利用する主なサービス:

- Vercel: Webアプリ本体（画面・API・ログイン・Cron削除）
- Railway: ワーカー本体（PDF/リーフ画像レンダリング、AIキャッチコピー・AI背景生成ジョブの処理）として**現在稼働中**
- Supabase: DB、Storage
- Gemini API: OCR、文章生成、AI背景画像生成
- Google Drive API: 確定リーフPNGの保存先

為替換算:

- 1 USD = 150円から160円で概算
- 実際の請求額は為替、税、各サービスの請求条件で変わります

公式料金ページ:

- Gemini API Pricing: https://ai.google.dev/gemini-api/docs/pricing
- Supabase Pricing: https://supabase.com/pricing
- Railway Pricing: https://railway.com/pricing
- Vercel Pricing: https://vercel.com/pricing

## 2. Gemini API

### 画像生成

現在の環境変数では、AI背景画像用モデルは以下です。

```text
IMAGE_GEN_MODEL=gemini-3.1-flash-lite-image
```

公式料金では、`gemini-3.1-flash-lite-image` の1K画像出力は以下です。

```text
$0.0336 / 1K image
```

円換算:

| 為替 | 1枚あたり |
|---|---:|
| 150円/USD | 約5.0円 |
| 160円/USD | 約5.4円 |

資料上は、余裕を見て **AI背景画像1枚あたり約5〜6円** と説明するのが安全です。

### 画像生成コスト例

| 生成枚数 | 150円/USD換算 | 160円/USD換算 |
|---:|---:|---:|
| 100枚 | 約504円 | 約538円 |
| 500枚 | 約2,520円 | 約2,688円 |
| 1,000枚 | 約5,040円 | 約5,376円 |
| 3,000枚 | 約15,120円 | 約16,128円 |

### OCR、文章生成

OCR、キャッチコピー、背景プロンプト、アソート補助には以下を使います。

```text
LLM_MODEL=gemini-3.1-flash-lite
```

OCRや文章生成は、画像生成に比べると1件あたりの単価は小さめです。ただし、PDFページ数、画像解像度、帳票の複雑さによって入力トークン量が変わります。

運用上は、コスト影響が大きいのは主にAI背景画像生成です。

## 3. 課金しない場合と課金した場合

### 課金しない場合

想定:

- Vercel Hobby（検証・デモ限定。本番公開には不可）
- Supabase Free
- Railway Trialのみ
- Gemini APIの無料枠または課金なし
- AI背景生成を極力使わない

メリット:

- 月額固定費を抑えられる
- テスト運用には向いている

注意:

- Railwayは常時起動のワーカーが必須のため（PDF/リーフ画像生成に使用）、Trialの一度きり$5クレジットはすぐ消費します。実運用ではHobby以上が前提です。
- Gemini画像生成は無料枠対象外または制限がある可能性があります。
- Supabase FreeはDB 500MB、Storage 1GBなどの上限があります。
- Supabase Freeは1週間未使用でプロジェクトが一時停止される可能性があります。
- 本番運用では、無料枠だけに依存すると突然止まるリスクがあります。

### 課金した場合

想定:

- Vercel Proまたは継続利用可能なプラン
- Supabase Pro
- Gemini APIは従量課金
- Railway Hobby以上（現在の運用形態）

メリット:

- 無料枠停止のリスクが下がる
- 保存容量、ログ保持、実行環境が安定する
- 本番トラブル時の調査がしやすい

注意:

- Gemini画像生成は使った枚数に比例して増えます。
- Supabase Storageは商品画像、元ファイル、生成リーフが増えるほど増加します。
- Railwayは起動時間、CPU、メモリ、通信量で費用が増えます。ワーカーは常時起動が前提のため、使用量はほぼ固定的に発生します。

## 4. Supabase

公式料金ページ上のFree枠の主な値:

- Database: 500MB / project
- Storage: 1GB included
- Egress: 5GB included
- Free projects are paused after 1 week of inactivity
- Free plan gives 2 active projects

Proの主な値:

- $25/monthから
- Database: 8GB included
- Storage: 100GB included
- Egress: 250GB included

### このシステムでSupabaseに溜まるもの

DB:

- 見積書レコード
- シート情報
- 商品情報
- アソート情報
- リーフ情報
- ジョブ情報
- OCRメトリクス

Storage:

- 元見積ファイル
- 複数資料の元ファイル
- 商品画像
- 生成済みリーフPNG
- PDF
- Gmail拡張時のEML、添付ファイル

### 保存容量の概算

1案件あたりの概算:

| 項目 | 想定サイズ |
|---|---:|
| 元Excel/PDF | 1〜10MB |
| 商品画像 | 10〜50枚 × 100〜500KB |
| リーフPNG | 10〜50枚 × 0.5〜2MB |
| DB行データ | 数MB未満 |

軽めの案件:

```text
1案件あたり 20〜50MB
```

画像が多い案件:

```text
1案件あたり 100〜200MB
```

Free Storage 1GBでの目安:

| 1案件あたり | 1GBに到達する件数 |
|---:|---:|
| 20MB | 約50件 |
| 50MB | 約20件 |
| 100MB | 約10件 |
| 200MB | 約5件 |

このシステムでは、見積書は取り込みから6ヶ月後に自動削除される設計です。月に20件以上取り込む場合や画像が多い案件が続く場合は、Supabase Proを検討した方が安全です。

## 5. Vercel

このシステムでは、VercelをWebアプリの入口として使う想定です。

Vercelで動くもの:

- 画面表示
- 見積書アップロードAPI
- ログイン
- リーフ編集画面
- 確定リーフ画面
- Google Drive転送API
- Cron削除

コストの考え方:

- Hobby: 無料。ただしVercel公式規約上「個人・非商用プロジェクト向け」のプランであり、クランツ様の業務で本番利用する用途には対応していません。
- Pro: $20/user/月から。商用・本番運用にはこちらが前提となります。

注意:

- 本番運用（クランツ様に実際にお使いいただく環境）は、規約上Proプラン以上での契約が必要です。Hobbyのまま本番公開すると規約違反となるおそれがあるため、検証・デモ目的以外では使用しないでください。
- Vercel側に環境変数を設定しないと、本番画面では機能しません。
- Railwayに環境変数を入れても、Vercelの画面には反映されません。
- 本番入口をVercelにする場合、Vercel側に全ての本番環境変数を入れてRedeployしてください。

## 6. Railway

**Railwayは、現在このシステムのワーカー本体として常時稼働しています。**

具体的には、以下の処理をRailway上の常駐プロセス（`npm run worker`）が担当しています。

- ジョブキューのポーリング（見積書取込、画像生成などの非同期処理）
- リーフ画像・PDFのレンダリング（Puppeteer。Vercelのサーバレス環境では動作しないため、この処理はRailway側で行う設計です）
- AIキャッチコピー生成、AI背景画像生成のジョブ実行

Vercel・Railwayどちらか一方だけでは、リーフ画像は生成されません。**Vercelが画面・API、Railwayが画像/PDF生成、という役割分担で常に両方が動いている構成です。**

公式料金ページ上の主な値:

- Free Trial: 一度きりの$5クレジット
- Hobby: $5/month、$5分の利用料込み
- Memory: $0.00000386 / GB-second
- CPU: $0.00000772 / vCPU-second
- Egress: $0.05 / GB
- Object Storage: $0.015 / GB-month

### Railwayコストの目安

ワーカーは常時起動が前提のため、Trialの$5クレジットやHobbyの$5込み利用料はすぐに消費されます。

常時起動に近い場合のざっくり目安:

- 1GBメモリを常時使うだけで、月約$10前後になる可能性があります。
- 0.5GBメモリ常時なら、月約$5前後が目安です。
- CPU使用、通信量、ディスク使用が増えると追加されます。

おすすめ:

- Railwayは月$5〜$20程度の費用を、固定的に発生するコストとして見込んでください（Vercelとは別枠の費用です）。
- サービスを誤って削除・再作成すると環境変数が消え、ワーカーが起動できなくなります。設定後はRailway側のService Variablesを変更しないでください。
- Railway側の詳しい必須環境変数は「環境変数と設定一覧」資料の該当章を参照してください。

注意（重要・残クレジットについて）:

- RailwayのプロジェクトはTrial/クレジット制です。画面右上に「残り◯日」または「残り$◯◯」の表示が出ている場合、それを使い切るとワーカーが強制停止し、リーフ画像生成が全て止まります。
- 支払い方法（クレジットカード等）を登録し、クレジット切れの前に有料プランへ移行してください。
- 定期的にRailwayダッシュボードの残クレジット表示を確認する運用をおすすめします。

## 7. Google Drive

Google Drive API自体は、通常の範囲では大きな追加費用が発生しにくいです。

ただし、Drive側の保存容量はGoogle Workspaceの契約容量に依存します。

保存されるもの:

- 確定リーフPNG

保存先:

```text
フォルダ名: リーフ画像確定
フォルダID: 1pGINY-Avt5bjrqNn_BD3BFPILC0E4AEz
```

注意:

- Drive転送先フォルダは、Googleサービスアカウントに編集権限で共有する必要があります。
- 確定リーフPNGが増えると、Drive側の容量も増えます。
- Google Driveに保存された確定リーフPNGは、システムの手動削除や6ヶ月自動削除では消えません。不要になった場合はDrive上で手動削除します。

## 9. コストを抑える運用

- 取り込み時のAI背景自動生成はOFFのままにする
- 背景生成は、採用候補のリーフだけ手動で実行する
- 不要な見積書は手動削除する
- 確定しないテスト取り込みは早めに削除する
- 6ヶ月保管が長すぎる場合は、保管期間を短縮する
- Railwayのサービス変数（環境変数）は、一度設定した後は誤って削除・変更しない

## 10. 先方への説明文

運用コストとして一番変動するのはAI背景画像生成です。現在のモデルでは、背景画像1枚あたり約5〜6円程度を見込んでいます。

Supabaseは無料枠でもテスト運用できますが、商品画像や生成リーフ画像が増えると1GBのStorage上限に近づきます。安定運用する場合は、Supabase Proなど有料プランの検討が必要です。

Railwayは、リーフ画像・PDFの生成処理を担うワーカー本体として、現在すでに常時稼働しています。Vercel（画面・API）とRailway（画像/PDF生成）の両方が揃って初めてシステム全体が動く構成のため、Railway側の費用は毎月固定的に発生するものとしてご認識ください。

Vercelは無料のHobbyプランもありますが、規約上は個人・非商用プロジェクト向けです。クランツ様の業務で実際にお使いいただく本番環境としては、Proプラン（$20/user/月から）でのご契約をお願いいたします。
